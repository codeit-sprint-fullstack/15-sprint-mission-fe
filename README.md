# 판다마켓 스프린트 미션

프론트엔드 스프린트 미션으로 제작한 판다마켓 랜딩 페이지, 로그인 페이지, 회원가입 페이지입니다.

## 배포 링크

https://sprint-15-fe-mission2.netlify.app/

## 구현 페이지

- 랜딩 페이지: `/`
- 로그인 페이지: `/login`
- 회원가입 페이지: `/signup`
- 상품 목록 페이지: `/items`
- Privacy 페이지: `/privacy`
- FAQ 페이지: `/faq`

## 주요 기능

- 상단 네비게이션 바 고정
- 로고 클릭 시 루트 페이지로 이동
- 로그인 버튼 클릭 시 로그인 페이지로 이동
- 구경하러가기 버튼 클릭 시 상품 목록 페이지로 이동
- Privacy Policy, FAQ 링크 연결
- SNS 아이콘 외부 링크 연결
- 로그인/회원가입 페이지 input focus 스타일 적용
- 비밀번호 입력창 눈 모양 아이콘 추가
- CSS 변수로 palette 색상 관리
- reset.css 적용
- rem 단위 기반 스타일링 적용
